# Team Availability Tracker

## Project Overview
A Full Stack web application that helps track team members' availability in real time.

## Features
- View all team members
- Update status (Available, Busy, Away)
- MongoDB database integration
- REST API using Express.js
- Responsive dashboard
- Live auto-refresh

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Git & GitHub
